{{define "email-settings"}}

Email delivery

Choose one provider for outgoing email. Save changes and restart every replica to activate them.

SMTP

Certificates are verified. Authentication uses AUTH PLAIN over TLS; leave both username and password empty for an authenticated network relay that does not require SMTP credentials.

Alibaba Cloud Direct Mail

Use a verified sender address in this region and a RAM identity with dm:SingleSendMail permission. Sender names have a 15-character limit.

AWS SES

Leave all three credentials empty to use the AWS credential chain, including workload IAM roles. The identity needs ses:SendEmail permission. Verify the sender in this region; sandbox accounts also require verified recipients.
